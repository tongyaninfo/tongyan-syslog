# Syslog.Api

单一 ASP.NET Core 宿主，组合 Ingest 模块；当前实现控制数据与管理 HTTP API。

## 已有代码

- 会话登录、注销、当前账号与仅管理员角色授权；来源权限范围由服务端管理库提供。
- 首次配置状态查询和仅本机 HTTPS 提交的首个管理员初始化。普通启动和状态查询不建库或迁移；新库显式提交依次采用 `001` 和监听配置 `002` SQL，既有版本 1 仍需单独显式迁移。
- 管理员账号分页查询、新建、改名、启停及为其他账号重置密码。变更复核当前会话，采用现有会话版本做乐观并发校验，审计失败整体回滚。禁止停用当前账号及最后一名启用管理员。
- SQLite 管理员、会话、来源、每来源保留天数、发号区间及操作审计；管理变更与审计同事务提交。
- 来源查询/新增/更新、日志检索/详情和运行状态入口；统一 ApiResult 与真实 HTTP 状态码。
- 显式控制库初始化和管理员引导命令；普通 Web 启动不创建表或默认账号。
- 依赖注入组合解析器、队列、暂存、ClickHouse HTTP 客户端与默认关闭的接收工作器。
- `GET/PUT /api/admin/v1/system/listeners` 管理四协议接收配置，保存和审计同事务、版本冲突受控。`PUT /api/admin/v1/system/listeners/reception` 控制运行中的监听器，重新开启时应用最新保存端点。响应返回保存、运行快照和待应用状态。证书只返回引用标识，迁移入口为 `--migrate-listeners`。详见[接收配置](../../../docs/spec/接收配置与RELP.md)。

## 未完成与边界

细分角色/设备组授权、解析器管理、告警、导出、回放、历史保留调整、物理清理和备份恢复尚未实现。已有管理台同源静态托管。当前保留设置作用于后续接收事件，不能追溯改变历史到期时间。HTTPS 的实际入口与证书需在交付环境配置并验证，本轮没有部署结论。

初始化路由为 `/api/admin/v1/setup/status` 和 `/api/admin/v1/setup/admin`，用户管理路由为 `/api/admin/v1/users`。新建及实际改名采用 3～64 位 ASCII 字母、数字、点、横线或下划线。历史 Unicode 用户名登录不变，原名不变时可启停。账号改名、启停和密码重置递增 `session_version` 并撤销会话，用户本人继续使用现有改密接口。未提供删除账号接口。

Controller 不实现协议解析或直接拼接 SQL；日志存储经 ILogStore 调用，SQLite 管理写入经控制服务执行。不暴露任意命令/路径/上游地址，异常响应不包含存储地址、口令或堆栈。

详见[接口合同](../../../docs/api/README.md)、[存储实施合同](../../../docs/spec/首批存储实施合同.md)、[后端规则](../../AGENTS.md)。
