# Syslog.Ingest

由 Syslog.Api 宿主组合的类库，负责接收、暂存和 ClickHouse 日志访问，不是第二个必需常驻宿主。

## 已有代码

- 未登记设备在许可网段内使用独立有界内存缓存，每 IP 最近最多 100 条；重启清空，一键登记后仅新日志进入正式流水线。停用来源和快照不可用继续拒收，详见[暂存说明](../../../docs/spec/未登记设备暂存.md)。

- UDP、TCP、TLS、RELP 接收工作器与帧读取；来源匹配、限速、连接与超时预算。Ingest.Enabled 默认 false，每个监听器另有 Enabled 开关，不会默认开放端口。
- 每个监听器独立报告端点、状态与错误码；某个端口或 TLS 证书启动失败不撤销其他监听器。来源快照不可用仍统一拒收，恢复时不清除其他端点的启动故障。
- TCP、TLS、RELP 的连接诊断按监听端点与来源 IP 分开记录。每个组合仅保留最近一次故障，接收端成功接纳同一来源的后续报文时移除该项。诊断最多保留 256 条，超过上限时淘汰最旧记录，监听重设时重建状态。
- 明文 RELP 支持版本 0（librelp）和版本 1 的协商、open/syslog/close 与 rsp、事务顺序、字节长度帧和有界确认等待。注册日志在现有文件暂存成功后确认；未登记日志按既定观察模式仅在内存缓存成功后确认，重启仍清空。ACK 不是 ClickHouse 入库确认；确认丢失后的重发可能产生重复日志。
- 条数/字节双限制队列，超长、空报文与队列溢出明确计数。
- 解析、集中发号、统一批次身份、文件暂存与入库分阶段计数。
- 实时看板使用独立 `LiveLogBuffer`：已登记来源解析后采集，含忽略级别与解析失败报文；正常日志在分配业务 ID 后、写入暂存前进入缓存，忽略日志不发号、不暂存、不入库。入库重试和启动恢复不重复追加，观察结果不代表已入库。
- 实时缓存默认每设备 5000 条、全局预算 512 MiB；按来源条数和估算内存预算淘汰，配置缩容立即生效，进程重启清空。来源及淘汰水位最多 10000 项，超过后重置缓存世代；快照/增量使用世代与十进制序列发现缺口，每次最多检查 8192 条记录，空页也可能带继续读取游标。
- 实时摘要不携带原文字节、结构化数据和批次/原始时间/进程/消息标识；正文最多 1024 字符并标记截断，主机/应用名最多 255 字符，超长时以省略号结尾。详情按缓存 ID 读取完整证据，字段筛选仍基于未截断的缓存内容。
- 文件暂存带校验、独占所有权和发送标记；ClickHouse 暂时不可用、写入结果未确认或启动发现 sending 批次时，使用原批次退避重试，确认成功后继续下一批。写入前合同检查拒绝仍明确报错并保留批次。
- ClickHouse HTTP 批量写入、参数化来源范围查询、30 天时间上限、500 条分页上限、过滤/权限绑定游标、受控详情与原文字节。
- [初始化 SQL](Data/events.sql)：非复制 MergeTree 月分区、text 索引、ZSTD 压缩及有限插入去重窗口；不启用自动删除 TTL。

## 限制

最低 ClickHouse 目标版本 26.8；已在本机 ClickHouse 26.8 验证实际入库和分页，未做容量验收。正文查询目前仅区分大小写的 ASCII 全词 AND，中文/纯符号返回 unsupported_search_token；不支持任意子串、正则或完整历史查询任务。列表不返回原始字节，详情才读取 raw_base64 并解码。

文件写入刷盘不等于目录项在掉电后必然持久；未持久消息、损坏磁盘与发送标记丢失仍有风险。已确认但中途回收失败的 acked 残留使启动明确失败为 spool_ack_cleanup_required，该批不会重发。

不负责账号、管理 HTTP 或解析算法。单宿主退出同时影响接收和管理；没有进程隔离或高可用保证。库与迁移显式维护，不在启动中建库、修改防火墙或设备。

## 验证边界

现有测试使用纯内存队列/暂存替身、模拟 HttpMessageHandler 和流输入。RELP 当前是独立 TCP 传输，TLS 监听器提供 Syslog over TLS，未实现 RELP over TLS / STARTTLS。真实 UDP/TCP/TLS/RELP 端口、证书、发送端互操作、文件暂存掉电/回收以及 ClickHouse 索引性能仍需分别获得环境授权并验证。
