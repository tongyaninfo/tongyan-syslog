# Syslog.Engine

独立解析类库，已建立 RFC 5424 / RFC 3164 基础解析与流式帧解码。

## 当前实现

- 解析 PRI、时间、主机、应用、进程、消息标识、结构化数据与正文，输出原始字节、解析状态和失败原因。
- 无年份/时区的时间使用调用方提供的接收时间与来源时区，保持确定性；不直接读取当前系统时间。
- TCP 字节计数与换行帧解码，覆盖半包、粘包、上限和非法长度；网络连接与超时由 Ingest 负责。
- RELP 字节帧解码，校验事务号、命令、负载长度与 LF 尾部；RELP 会话协商、回应及确认深度由 Ingest 负责。
- 无效报文返回明确结果，原文证据不因解析失败被替换或隐式转换为 UTF-8。

厂商正文深度适配、自定义解析器版本流程、告警窗口求值与历史回放服务仍未实现。基础协议可解析不等于所有交换机/ESXi 版本完成适配。

## 边界与验证

不依赖 ASP.NET Core、数据库、网络或系统命令。单元测试使用合成报文验证 RFC 字段、时间边界、非法输入与帧边界；不启动监听器或写库。测试可在本机直接运行。
