# Syslog.Api.Tests

控制面测试工程已建立。当前使用获准隔离 SQLite 与合成账号/来源，验证初始化边界、发号、管理员会话、来源保留设置与审计事务；HTTP 路由/中间件测试随真实测试文件维护。用户管理覆盖分页过滤、重名、版本冲突、改名/停用/重置后的会话撤销、最后管理员和当前账号保护、旧 Unicode 用户名兼容，以及审计失败回滚。首次配置覆盖缺库状态只读、显式创建、损坏/不兼容库拒绝、并发一次性提交、全禁用账号不重开、本机 HTTPS 和转发头限制。

不连接共享数据库或 ClickHouse，不启动真实 Syslog 端口，不执行生产迁移。内存测试库随连接结束释放，文件测试库与静态资源保留在忽略的测试输出目录，未获授权不自动删除。Web 管理台同源静态路由已测试，浏览器验收由前端验证负责。导出、回放和删除尚未实现，不能宣称对应业务已完成验收。

从仓库根运行：

~~~sh
dotnet test backend/tests/Syslog.Api.Tests/Syslog.Api.Tests.csproj
~~~
