# 告警规则

本目录为占位目录，当前**没有告警规则文件**。规划用于存放可版本化的告警规则：关键字匹配、频率阈值、关联窗口、静默与冷却。

## 约定

- 每条规则必须写明：触发条件、阈值、统计窗口、静默期、冷却期、通知渠道、影响范围与作者。
- 规则求值保持确定性：输入为事件快照与规则版本，输出为命中明细与动作；不在求值中读库、写文件或执行命令。
- 同一事件不得因规则重复触发而无限通知；静默与冷却状态可查询。
- 区分「规则命中」「已通知」与「通知失败」三种状态，通知失败保留可观测记录，不假报已送达。
- 测试样本使用合成报文，不包含真实来源地址、账号或业务标识。

规则总则见[规则说明](../README.md)。
