# Syslog 规则

本目录用于存放可版本化的解析器定义、告警规则与测试样本。当前**尚无规则文件**，只有本说明；目录与子目录为规划占位。

## 规划结构

```text
rules/
├── parsers/         # 解析器定义：RFC 5424 / 3164、sshd、Web、网络设备、容器、JSON / CEF
├── alerts/          # 告警规则：关键字、频率阈值、关联窗口、静默与冷却
├── tests/           # 合成报文样本与回归用例
└── README.md
```

## 规则来源与许可

- 内置解析器由本项目维护；引用第三方解析器、设备格式或规则集时，先确认许可范围与分发方式，未经确认不提交进仓库，也不随镜像发布。
- 导入第三方规则保留原始来源地址、版本、许可、导入时间与校验摘要，不裁剪版权声明。
- 测试样本必须使用合成报文与文档保留网段（如 `192.0.2.0/24`），不包含真实业务日志、账号、内部域名或来源地址。

## 版本与发布

- 解析器与告警规则只通过「草稿 → 观察 → 生效 → 回滚」流程变更；正在生效的规则不可直接编辑。
- 每次变更保留：版本标识、规则数量、来源、变更说明、影响范围、回滚目标与验证样本。
- 加载失败、格式错误或摘要不匹配时拒绝启用，保留上一版本继续运行并报告状态；不默认放行未知格式。
- 回放历史报文时使用当时的解析器版本，回放结果幂等，不重复累计。

## 格式约定

- 解析器定义必须写明：适用来源、协议或格式、字段映射、版本、作者、创建时间、已知误判与发布时间。
- 告警规则必须写明：触发条件、阈值、统计窗口、静默期、冷却期、通知渠道与影响范围。
- 规则文件只保存数据，不存放可执行代码；不在规则中拼接命令、SQL 或文件路径。
- 停用规则保留历史而不是直接删除；删除属于危险操作，需范围、审计与确认。

## 与其他目录的关系

- 解析与告警的实现位于 `backend/src/Syslog.Engine/`；本目录只保存定义与样本。
- 规则的导入、观察、生效与回滚由 `Syslog.Api` 的管理接口与页面完成，本目录不是运行时编辑入口。
- 引擎的测试直接引用 `rules/tests/` 的合成样本，见 [Syslog.Engine.Tests](../backend/tests/Syslog.Engine.Tests/README.md)。
