# 规则测试样本

本目录为占位目录，当前**没有测试样本**。规划用于存放解析器与告警规则的合成报文样本与回归用例，供单元测试和离线回放使用。

## 约定

- 只使用合成报文：主机名、来源地址、账号、应用名与日志正文均为示例，不包含真实业务日志或个人数据。
- 来源地址使用文档保留网段（如 `192.0.2.0/24`、`198.51.100.0/24`、`203.0.113.0/24`）。
- 样本应覆盖：RFC 5424 / 3164 正例、无时区时间、结构化数据、非法 PRI、超长与截断报文、未知格式、粘包/半包边界。
- 每个样本注明期望的解析状态、解析器版本与关键字段；回归用例在解析器或规则变更后重跑。
- 回放必须幂等：同一原始报文重复回放不重复累计事件或告警。

规则总则见[规则说明](../README.md)；测试项目见 [Syslog.Engine.Tests](../../backend/tests/Syslog.Engine.Tests/README.md)。
