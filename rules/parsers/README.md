# 解析器定义

本目录为占位目录，当前**没有解析器文件**。规划用于存放可版本化的解析器定义：协议解析（RFC 5424 / 3164）与来源格式解析（sshd、Web 服务器、网络设备、容器、JSON / CEF）。

## 约定

- 每个解析器必须写明：适用来源、协议或格式、字段映射、版本、作者、创建时间、已知误判与发布时间。
- 解析器只做字段映射与归一化，不拼接命令、SQL 或文件路径，不依赖网络与数据库。
- 定义格式（JSON / YAML 或代码内置）与版本回滚方式待 [ADR](../../docs/adr/README.md) 确认；确认前不提交「生效」规则。
- 解析失败必须返回明确原因并保留原文；未知格式返回「未匹配」而不是猜测字段。
- 测试样本放 [tests/](../tests/README.md)，使用合成报文与文档保留网段。

规则总则见[规则说明](../README.md)。
