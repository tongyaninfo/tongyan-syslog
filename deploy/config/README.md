# 部署配置示例

本目录为占位目录，当前**没有配置示例或生产配置**。规划在实施方案确认后提供脱敏的 `appsettings.Production.example.json`，以及接收监听器、保留与告警的示例配置。

## 规划

- 示例配置只含占位值：监听地址、端口、数据库路径、证书路径、保留期、告警渠道均不写真实环境信息。
- 管理面与接收面配置分开：`Syslog.Ingest` 关注监听器、限速、队列与批量；`Syslog.Api` 关注 HTTPS、认证、检索上限与导出。
- 数据库路径、归档目录与备份目录显式配置，默认不指向仓库目录或临时目录。
- TLS 证书、通知渠道凭据与 Webhook 密钥通过环境变量或受控密钥机制注入，示例中只保留占位符与「必填」说明。
- 配置变更与版本绑定：解析器与告警规则版本、配置修订号能被运行状态查询读回，避免「配置已改、进程未生效」的误判。

## 边界

- 示例不得包含真实主机名、内网地址、账号、口令、Token、私钥或真实日志样本。
- 不把示例配置直接当作生产配置复制使用；部署前须按环境填写并核对。
- 配置加载失败、证书无效或端口冲突时拒绝启动对应组件并报告，不静默降级为明文或默认值。

入口见[部署说明](../README.md)与[接口合同](../../docs/api/README.md)。
