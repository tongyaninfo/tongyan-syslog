# ADR-0007：实时日志有界缓存

- 日期：2026-11-11
- 状态：已接受，用户明确批准一张配置表、显式迁移及本机隔离验证；未授权部署。

## 决定

以单宿主内存缓存承载实时日志，默认每设备 5000 条、总预算 512 MiB。包含正常处理及忽略不入库的日志，入口处理时只追加一次，不复用持久写入重试。

仅在 SQLite 新增 `live_log_settings` 配置表，版本 5 经显式维护命令迁移至 6。配置及审计原子提交后热应用内存限制，普通启动不自动迁移。

沿用现有 SignalR 和管理员 Cookie，使用独立 Hub、序号与 epoch、有界批量和超时。暂停或断线期间超出缓存保留范围时显式提示缺口。日志正文保持纯文本，摘要与详情分开，来源授权由服务端控制。

## 取舍

无需为忽略日志增加磁盘或 ClickHouse 写入；代价是重启清空且容量不足会淘汰。缓存字节为保守记账预算，不代表整个进程的操作系统内存硬上限。详情展示不等于成功入库，入口丢弃也无法在缓存找回。

完整边界见[实时日志看板](../spec/实时日志看板.md)。
