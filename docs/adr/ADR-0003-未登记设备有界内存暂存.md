# ADR-0003 未登记设备有界内存暂存

- 状态：接受。
- 日期：2026-11-10。
- 依据：用户确认[未登记设备暂存方案](../spec/未登记设备暂存.md)，明确接受内存暂存、重启清空。

## 背景与决定

首批实现只接收已登记启用的实际发送 IP，未登记报文直接拒绝，无法在管理台确认新设备发送情况。新增许可网段内的观察入口，每 IP 最多保留最近 100 条原始报文，独立设置全局设备、字节、速率、连接与 TLS 握手预算。

观察样本仅存在于单宿主内存，不写 SQLite 或 ClickHouse，不取得正式事件身份。容量超限滚动淘汰并计数，进程退出后不恢复。样本定位键绑定当前启动周期，不能作为业务事件 ID 使用。

管理台提供单独菜单与管理员只读接口，完整原文按单条读取；一键登记复用现有来源写入与可靠审计。新事件在来源快照刷新后进入正式流水线，旧样本释放且不补写。已停用来源与控制库故障不会进入观察入口。

## 理由与影响

内存方案满足接入排查所需的有限样本，避免扩大长期日志留存范围和引入数据库迁移。代价是重启、容量淘汰、来源登记后无法恢复此前样本。实际对端 IP 是分组依据，不解决 NAT / 中继后的资产区分。

新增功能改变未登记流量的处理方式，但不自行开启监听、放行防火墙或启动部署。许可网段采用最高配置层整体替换，空列表拒收，防止配置合并保留已撤销网段。正式存储失败时仍遵循全局停止接收策略。

## 验证与后续

使用合成报文、内存替身、模拟流、隔离 SQLite 和进程内 TestServer 验证接收分流与管理接口；浏览器使用回环合成预览验证页面。实际结果以本机隔离运行为准。真实设备、TLS 握手与负载性能仍需获准环境验收。
