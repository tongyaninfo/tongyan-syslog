## 脱敏要求

- 使用合成数据：主机名、来源 IP、应用名、账号、日志正文、解析器命中与告警内容全部为示例，不使用真实业务日志、真实主机信息或真实用户数据。
- 来源地址使用文档保留网段（如 IPv4 `192.0.2.0/24`、`198.51.100.0/24`、`203.0.113.0/24`，IPv6 `2001:db8::/32`）；Cookie、Token、`Authorization` 与 TLS 私钥不出现。
- 日志截图只展示合成报文，不包含真实登录记录、业务路径、内部域名、邮箱、手机号或可定位到个人/组织的网络信息。
- 不展示宿主端口放行配置、交付服务器真实主机名、地址、路径与命令输出；涉及部署的截图只能使用占位环境。
- 截图中的角标、浏览器书签、系统通知栏、终端历史等无关内容裁掉或打码。

## 命名与引用

- 命名：`<主题>-<视口/场景>.<扩展名>`，例如 `log-search-desktop.jpg`；同名多语言用 `-zh-CN` / `-en-US` 区分。
- 引用使用相对路径，中文替代文本说明页面内容并注明合成演示数据；示例文件名仅供说明，实际引用以本目录真实文件为准。
- 图片只用于说明界面与交互，不作为功能、性能或接收能力已验收的证明；文档中注明「合成演示数据」。

## 其他

- 大图先压缩，避免把原始高分辨率截图直接提交；动态演示优先使用短 GIF 或链接，不提交大视频。
- 设计稿源文件、导出中间件与未脱敏原图不进入仓库。
- 删除或替换截图时同步更新引用，避免死链。
