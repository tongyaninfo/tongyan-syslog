## 维护规则

- 文档使用中文、UTF-8、相对路径；不写个人绝对路径、真实账号、密钥或连接串。
- README 负责导航；方案、接口、决定、变更、版本分别维护，避免多份规则互相漂移。根 [AGENTS.md](../AGENTS.md) 是开发行为约束，不在文档里复制整段规则。
- 区分「规划」「已实现」「已验证」「已部署」四种状态；目录存在、文档写完、模板可运行都不能推导为能力已实现或已上线。
- 决策进 ADR，方案进 `spec/`，接口进 `api/`，版本与升级进 `releases/`；同一事实只维护一处，其余用链接引用。
- 删除、改名或移动文档时同步更新所有引用；提交前检查本地链接与状态标注。
- 截图和示意图使用合成数据，主机名、域名、IP、账号与日志内容脱敏，详见[文档资源](assets/README.md)。
