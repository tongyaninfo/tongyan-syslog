# 实时日志看板

## 授权与范围

2026-11-11 用户确认新增实时看板，允许新增一张配置表和显式迁移，仅在本机隔离环境验证，不部署。展示已登记来源的接收处理记录，独立于 ClickHouse；未登记设备沿用已有独立样本页。

## 缓存与处理语义

- 每设备默认最新 5000 条，正常与按严重级别忽略的日志合计计算；可配置 100～50000 条。
- 总预算默认 512 MiB，可配置 16 MiB～2 GiB。条数或容量到限淘汰最早记录，不保证所有设备同时保有上限条数。页面显示占用、淘汰及拒绝计数。
- 忽略日志退出处理前进入缓存，保留原文字节，不分配数据库事件 ID、不写暂存或 ClickHouse。正常日志解析并分配事件 ID 后进入缓存；入库重试不重复追加。
- 实时可见表示已进入解析处理，不代表已经入库。入口队列丢弃的日志无法显示；暂存已满阻塞处理时，页面显示排队、丢弃和暂存满状态。
- 日志仅驻内存，宿主重启清空；停止接收或客户端清屏不清后端缓存。既有清空日志操作只处理 ClickHouse。
- 序号与缓存 epoch 组成临时标识，不替代集中事件 ID。元数据最多跟踪 10000 个来源，超过边界重置缓存和 epoch，客户端提示重新加载。

## 查询与传输

筛选包括接收时间、设备、严重级别、主机、应用、关键字及全部／正常处理／已忽略。主机和应用精确匹配；关键字与既有检索一致，支持区分大小写的 ASCII 字母数字整词 AND，不伪称支持中文全文检索。时间为 UTC ISO 8601，界面按北京时间显示；不填时间则跟随最新。

初次订阅最多 500 条摘要及水位；之后约每 250 ms 检查增量，每批最多 200 条，空闲每 5 秒心跳。每次发送复核管理员会话，来源范围从服务端读取。连接最多 32 个，每连接只允许一个在途发布，发送超时关闭连接，不阻塞接收。

摘要不含原文字节、结构化原文、原始时间字符串和其他仅详情需要的字段，正文最多 1024 字符，主机及应用名超长时截为 255 字符并标记省略；每批数据预算约 512 KiB。详情按临时 ID 读取完整内存原文，纯文本显示。浏览器整体最多保留 5000 条摘要，与后端每设备限制不同。

每次查询最多扫描 8192 条，达到扫描预算也返回 `budgetLimited/hasMore` 和已检查水位，允许空结果页携带下一页游标。历史查询继续加载更早记录，增量订阅在下一批继续追赶，不能将游标跨过未检查区间。

暂停只停止本浏览器订阅，恢复和重连携带 epoch、游标补取。缓存重启、淘汰或并发读取出现缺口时提示并重新取快照，不把不完整历史当作完整记录。筛选变更使用新订阅标识，迟到消息不得混入新结果。

## 接口

管理 API 前缀 `/api/admin/v1`，沿用管理员 Cookie、`ApiResult<T>`、写请求保护头和服务端权限。

| 接口 | 合同 |
| --- | --- |
| `GET /live-logs/settings` | `{settings:{version,perDeviceLimit,maxBytes},cache}` |
| `PUT /live-logs/settings` | 保存同字段，复核版本和会话，同事务审计，提交后立即调整缓存 |
| `POST /live-logs/query` | `{filter,epoch?,beforeSequence?,limit}`，返回摘要、epoch、水位、历史游标与统计 |
| `GET /live-logs/entries/{id}` | 内存详情及原文字节；淘汰后返回不存在 |
| `/hubs/live-logs` | HTTPS 同源 WebSocket，管理员 Cookie；拒绝 URL token |

Hub 方法 `Subscribe({subscriptionId,filter,epoch?,afterSequence?})` 返回 `ApiResult<bool>`。`LiveLogsUpdated` 事件含 `subscriptionId/kind/epoch/cursor/items/hasMore/nextBeforeSequence/resetReason/budgetLimited/cache/observedAt/ingest`；kind 为 `snapshot/append/heartbeat`。首次事件先于方法完成响应，客户端预先注册回调。`SessionExpired` 表示会话失效。

## 配置与迁移

唯一新增表 `live_log_settings`（控制库 v6）保存版本号、每设备限制、总容量、修改时间和操作者，日志正文不写 SQLite。新库显式初始化至 v6；既有库先到 v5，再在获准环境执行：

```sh
dotnet <应用路径>/Syslog.Api.dll --migrate-live-logs
```

普通启动不建表或迁移。旧库返回 `live_logs_migration_required`，停用实时缓存，既有功能继续使用。迁移可重复执行，异常结构不自动修复。正式库升级与部署仍需另行授权。

实际结果以本机隔离运行为准。本机合成数据、内存 SQLite 和浏览器验证不代表真实设备、ClickHouse 或长期负载验收。
