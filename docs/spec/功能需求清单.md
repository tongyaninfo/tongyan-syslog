# 通研 Syslog 功能需求清单

建立：2026-11-09；状态更新：2026-11-10。下表保留完整一期需求与验收目标；已有首批后端代码，尚未完成整体验收。已实现范围和限制见[首批存储实施合同](首批存储实施合同.md)，不能把本表的目标能力视为全部已交付。

适用规模：约 1000 台设备；用户后台自定义保留，常见 1～3 年；优先轻量单机。P0/P1/P2 定义见[产品规划](产品规划.md)。下表是需求验收依据，涉及网络、存储写入或删除的测试仅在获准隔离环境实施。

## 接入与来源

| 编号 | 优先级 | 行为与依赖 | 可执行验收点 |
| --- | --- | --- | --- |
| SRC-001 | P0 | 管理 1000 条设备资产，品牌/型号/版本/设备组/标签/时区/发送源独立保存 | 批量导入 1000 条合成资产；重复、非法地址逐行报告；修改有版本检查和审计 |
| SRC-002 | P0 | 为 UDP/TCP/TLS 提供可配置监听器 | 绑定冲突、证书无效、权限不足显示失败；保存配置不假报运行成功 |
| SRC-003 | P0 | 按设备版本提供接入参数与诊断 | 交换机与 ESXi 各至少一类实际版本完成合成标记验证；记录协议/帧/字段覆盖 |
| SRC-004 | P0 | 来源匹配区分资产、连接 IP、报文 hostname、中继 | NAT 后多个来源不错误合并；未登记来源进入有配额的待确认视图，不自动授信 |
| SRC-005 | P0 | 活跃、静默、预期缺报分别显示 | 无周期上报约定的安静设备不被标记为宕机；设置预期周期后才触发缺报告警 |
| SRC-006 | P1 | 接入 Linux、应用及家族产品格式 | 各适配有合成合同样例；不声称接入 ESXi 即获得 VM 内全部日志 |

## 传输与可靠性

| 编号 | 优先级 | 行为与依赖 | 可执行验收点 |
| --- | --- | --- | --- |
| ING-001 | P0 | UDP 一报文一边界，有大小、速率和队列上限 | 正常、超长、突发、乱序、重复均有明确结果；应用与 OS 丢弃分别记录 |
| ING-002 | P0 | TCP 支持字节计数与明确配置的分隔帧 | 中文字节长度、半包、粘包、非法长度、无分隔超时测试通过 |
| ING-003 | P0 | TLS 标准帧及厂商兼容模式分别登记 | 握手/信任链/主机名/过期失败可定位；不自动退回明文或关闭校验 |
| ING-004 | P0 | 支持 1000 来源长连接并预留余量 | 合成 2000 连接预算测试、重连风暴和握手限流；不以连接建立替代消息入库验证 |
| ING-005 | P0 | 有界内存队列与本地持久缓冲 | 存储暂停后按预算积压；重启恢复已持久数据；队列满时按策略背压/丢弃并计数 |
| ING-006 | P0 | 接收、持久暂存、解析、入库、丢弃分别计量 | 对合成序号报文核对每阶段数量，确认未刷盘窗口与未收到报文不可恢复 |
| ING-007 | P0 | 未确认写入自动重试，保持事件身份与批次身份 | 模拟写入成功但响应丢失，在 ClickHouse 去重窗口内重试不产生重复；记录去重窗口的边界 |

## 解析与证据

| 编号 | 优先级 | 行为与依赖 | 可执行验收点 |
| --- | --- | --- | --- |
| PAR-001 | P0 | RFC 5424/3164 基础字段及厂商正文解析 | PRI、结构化数据转义、无年份/时区、非法字节、缺字段都有预期结果 |
| PAR-002 | P0 | 原文按字节保存，解析失败仍可查 | 比对保存字节与输入，失败原因可见；显示截断与发送端可能截断的不同边界 |
| PAR-003 | P0 | 同存 eventTime、receivedAt、原始时间与置信度 | 跨年、时区、设备时钟异常、迟到数据不会被无提示地移动时间或漏查 |
| PAR-004 | P1 | 声明式解析器，草稿/观察/生效/回滚 | 非法定义拒绝启用；正则超时不能阻塞接收；观察结果不改变生效字段 |
| PAR-005 | P1 | 历史回放区分复现与修复 | 固定旧版本可复现，指定新版本生成修订；同事件同版本重跑不重复累计，默认不重发告警 |

## 查询与分析

| 编号 | 优先级 | 行为与依赖 | 可执行验收点 |
| --- | --- | --- | --- |
| QRY-001 | P0 | 时间、设备组、来源、严重级别、主机、应用筛选 | 多条件交集正确；所有查询服务端强制设备组权限 |
| QRY-002 | P0 | 精确字段、索引词匹配和受预算限制的子串查询 | 覆盖 IPv4/IPv6、MAC、接口名、中文短词、引号、通配符；验证索引命中和精确匹配，预算超限明确提示 |
| QRY-003 | P0 | 稳定游标翻页，明确迟到提交与刷新语义 | 同时摄入日志时，按稳定身份翻页无重复；迟到/修订提示刷新；不冒充事务快照，不伪造精确 total |
| QRY-004 | P0 | 详情、原文、前后文 | 内容转义、截断提示、完整字节受控下载；不执行 HTML/脚本 |
| QRY-005 | P1 | 30 天普通关键词与结构化筛选在线返回首屏，保留期内提供受控历史任务 | 按实施方案验证跨设备查询；1 年和 3 年边界数据可查；任务支持进度/取消/超时，历史任务不拖垮接收 |
| QRY-006 | P1 | 保存查询与受控导出 | 保存查询无隐式共享；导出前后校验权限，CSV 防公式注入，文件限量限期 |
| ANA-001 | P0 | 趋势、级别分布、Top 来源和解析失败分布 | 与已确认事件的明细统计一致；写入积压或修订中时明确标记 |
| ANA-002 | P1 | 跨设备时间线与预设排障视图 | 时间质量标记保留，显示同窗口事件而不自动断言根因 |

## 留存与容量

| 编号 | 优先级 | 行为与依赖 | 可执行验收点 |
| --- | --- | --- | --- |
| RET-001 | P0 | 全局/设备组/设备覆盖的后台保留策略 | 显示最终继承值；1/2/3 年和自定义可保存，策略版本与到期时间可追溯 |
| RET-002 | P0 | 原文和结构化详情共同保留到期 | 一年或三年前边界原文与详情可查；不默认仅保留统计、不静默归档 |
| RET-003 | P1 | 历史保留调整预览并异步执行 | 分清只作用新数据/同时作用历史；缩短先显示范围/条数估算/字节，确认后才执行 |
| RET-004 | P1 | 延长与缩短的状态可恢复 | 延长不恢复已删除数据；应用独占删除调度，重启恢复清理屏障，在途删除终结后再调整历史 |
| RET-005 | P0 | 到期不可查与物理清理分别可观测 | 到期查询过滤生效；后台清理延迟、已清理字节、失败及审计可查 |
| RET-006 | P0 | 容量预估与高水位治理 | 用实测每条落盘字节预测剩余天数；磁盘紧急时不未经授权删除未到期数据 |
| RET-007 | P1 | 可验证备份与恢复 | 隔离恢复后比对配置、权限、事件、原文和保留状态；报告恢复时间和数据缺口 |
| RET-008 | P2 | 可选离线归档和回读 | 明确离线数据不属于即时在线查询；校验完整性后才能按授权移除在线副本 |

## 告警与权限

| 编号 | 优先级 | 行为与依赖 | 可执行验收点 |
| --- | --- | --- | --- |
| ALT-001 | P0 | 关键字、严重级别、频率阈值 | 固定窗口、阈值、分组键正确，缺字段不错误命中 |
| ALT-002 | P1 | 有界关联窗口、静默、冷却、确认与恢复 | 端口抖动/登录失败样例符合阈值；重启和重复入库不产生通知风暴 |
| ALT-003 | P1 | Webhook 有持久状态、限次重试和去重标识 | 网络故障显示待重试/失败；对端返回成功与业务处理成功边界明确 |
| SEC-001 | P0 | 多用户、设备组权限、会话和 CSRF 防护 | 越权详情/检索/计数/导出失败；禁用账号旧会话失效；登录限速 |
| SEC-002 | P0 | 管理变更与可靠审计同事务 | 审计不可用不返回变更成功；保存与运行应用状态独立 |
| SEC-003 | P0 | 受控原文与脱敏显示 | 授权原文可见，未授权角色不能通过导出/通知/计数侧路取得数据 |
| SEC-004 | P1 | 安全通知与外部归属查询 | Webhook 防 SSRF/重定向绕过，配置秘密不输出；外部 IP 归属查询有超时、并发限制且可关闭 |
