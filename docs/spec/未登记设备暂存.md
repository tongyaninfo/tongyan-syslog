# 未登记设备暂存

依据：用户于 2026-11-10 确认新增「未登记设备」菜单、每 IP 最近 100 条内存样本和一键添加来源，接受重启清空。本功能扩展[一期实施方案](一期实施方案.md)中的有限配额待确认区，不新增数据库表或迁移，不替代正式日志库。

## 接收与身份

- 依据服务端实际看到的对端 IP 归组，IPv4 映射地址归一化；报文 hostname 不用作授权身份。NAT / 中继后的多个设备可能归为同一对端。
- 已登记且启用的来源走现有接收、解析和入库链路；已登记但停用的来源继续拒绝。来源快照不可用时停止接收，不把配置读取故障视为所有设备未登记。
- 未登记设备仅在既有监听启用、暂存功能启用且实际对端处于允许网段时暂存。UDP / TCP / TLS 共用此分流，TCP/TLS 仍受现有分帧、长度、超时和证书检查约束。
- 暂存不分配正式业务事件 ID，不解析或写入 ClickHouse；`sampleKey` 由启动随机标记与进程内序号组成，只用于定位内存样本，重启失效。

## 配额与配置

配置位于 `Ingest.UnregisteredDevices`，完整默认值见[配置示例](../../backend/src/Syslog.Api/appsettings.json)。总开关 `Ingest.Enabled` 仍默认 `false`，监听器仍为空；新增功能不会自动开启宿主端口。

| 配置 | 默认值 | 含义 |
| --- | --- | --- |
| `Enabled` | `true` | 允许在已启用监听上暂存未登记设备 |
| `AllowedNetworks` | 回环、RFC 1918 IPv4 私网、IPv6 ULA | 默认不收集公网未知来源；按实际环境配置 CIDR |
| 每 IP 样本数 | 固定 100 | 超出后淘汰最旧样本 |
| `MaxDevices` | 1000 | 未登记 IP 上限 |
| `MaxBytes` | 67108864 | 缓存总预算，包含原文字节和元数据估算 |
| `MessagesPerSecondPerAddress` / `MessagesPerSecond` | 100 / 1000 | 每 IP / 全局每秒速率 |
| `MaxConnections` / `MaxConnectionsPerAddress` | 64 / 2 | 未登记 TCP/TLS 连接配额 |
| `ConnectionsPerSecondPerAddress` / `ConnectionsPerSecond` | 5 / 20 | 建立连接速率 |

单条报文仍使用 `Ingest.MaxMessageBytes` 的现有上限，默认 65536 字节。缓存满时淘汰最旧样本或设备；全局预算可能使某个 IP 暂存不足 100 条。新建空白连接不能无限创建设备或速率记录。缓存、计数、样本键均仅存在于内存，重启清空。

`AllowedNetworks` 由最高优先级显式配置该数组的配置层整体替换；空数组表示不允许任何未登记 IP，避免缩小许可范围时残留默认网段。设备数和字节数当前可调低，硬上限分别为 1000 和 64 MiB。每 IP 速率状态独立于样本淘汰，最多保留 2048 个当前窗口地址，预算饱和时拒绝新增地址；其元数据也计入缓存预算。未知来源 TLS 握手另限 8 并发，共享总握手上限仍为 64。

正式写入流水线处于失败状态时，沿用全局停止接收策略，未登记暂存也停止；页面的「暂存配置已启用」不表示监听和入库健康。未登记设备转为正式来源，或正式来源改 IP 后变为未登记设备时，既有 TCP/TLS 连接关闭并要求发送端重连，从而重新取得对应连接配额。

暂存计数与正式解析、持久暂存、写入计数分开。页面展示暂存累计量、淘汰与拒绝量；淘汰包括滚动覆盖，不等同于正式日志存储故障。设备汇总中的首次时间和累计量属于当前缓存设备周期，设备被整体淘汰后重新出现时重新计算。

## 管理 API 与一键登记

接口均沿用管理员会话、统一 `ApiResult<T>`、并发限制及脱敏错误。

| 请求 | 返回 |
| --- | --- |
| `GET /api/admin/v1/unregistered-devices` | 有界设备列表 `items` 与缓存状态 `status`，不返回原文 |
| `GET /api/admin/v1/unregistered-devices/logs?peerAddress=...` | 最近最多 100 条摘要，最新在前 |
| `GET /api/admin/v1/unregistered-devices/sample?peerAddress=...&sampleKey=...` | 单条样本，`rawBytes` 为未经修改的字节 Base64 |

IP 参数非法返回 400；已登记设备、被淘汰设备/样本返回 404；来源读取故障返回脱敏 503。GET 不修改缓存。样本预览可能截断，完整字节通过单条接口读取，前端复用纯文本和十六进制证据组件。

一键登记复用 `POST /api/admin/v1/sources`，名称和来源地址均为当前 IP，时区 `Asia/Shanghai`、保留 365 天、启用接收。来源写入与可靠审计仍在同一事务内，失败不会报告成功；重复 IP 返回 409，不自动启用已停用来源。

成功后立即从管理列表隐藏已登记 IP；接收端在下一次来源快照刷新后切换为正式来源并释放对应内存样本（默认刷新周期 10 秒）。此前样本不会回填 ClickHouse。超限、重启、登记释放之后的样本均无法恢复。

## 验证边界

自动测试使用合成报文、内存服务、模拟流与 TestServer；API 来源写入使用获准隔离 SQLite，浏览器使用回环合成预览。没有因此授权真实接收端口、生产部署或 ClickHouse 初始化。实际检查结果以本机隔离运行为准。
