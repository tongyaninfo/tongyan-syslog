# 管理台前端

通研 Syslog 管理台已建立 React 19、Umi Max、Ant Design 6、Biome 和 Vitest 源码，沿用 Ant Design Pro 6.0.3 模板的最小工程基线与扩展点，保留其 [MIT 许可](LICENSE)。前端构建结果可复制到后端 `wwwroot`，由同源 HTTPS 服务提供。

## 当前状态

- 已有登录、总览、日志检索与详情、日志来源、日志保留页面，并接入现有管理 API 合同；没有为未实现能力添加占位导航。
- 新增首次管理员配置和用户管理，复用现有控制库及管理员角色。首次配置、账号启停、密码重置和并发修改均由后端校验。
- 样式沿用通研统一管理台风格：主色 `#1849a9`、浅色背景、白色卡片、紧凑表格、响应式布局及通研技术品牌资源；保持与通研其他产品一致的外观。
- 基线不引入 AI、地图、外网字体或 Git hooks；不复制参考项目的身份认证、第三方服务和业务依赖。依赖版本以 [package.json](package.json) 和锁文件为准。
- 本地检查与合成预览的结果以实际运行为准。源码、构建和预览不代表真实设备、ClickHouse、长期留存或性能验收通过；尚未生产部署。
- 一期界面范围为管理台，不包含桌面客户端、移动端独立应用或对外公开门户。

总览通过「当前待写入批次」与「当前本地暂存占用」显示积压，通过「当前日志数据库大小」显示 ClickHouse 日志库活跃数据在磁盘上的大小。无法取得数据库大小时显示「—」。

「实时看板」位于 `/live-logs`，仅管理员可访问。默认持续接收并搜索现存缓存，也可选择不超过 30 天的固定接收时间范围；来源、严重级别、主机、应用和关键词保持日志检索语义，额外可筛选正常接收或已忽略记录。编辑条件不会立刻切换订阅，点击「应用筛选」后才生效。筛选只保留在页面内存，不写入 URL 或浏览器存储。

每设备默认缓存最近 5000 条，全局默认预算 512 MiB；设置支持每设备 100～50000 条、全局 16～2048 MiB，保存立即生效，缩容明确提示淘汰。界面展示实际缓存条数、占用、设备数、淘汰与拒绝量。首次读取最近 500 条，向前每次加载 500 条，虚拟表格最多保留 5000 条摘要；详情按需从缓存取得并复用原始报文纯文本、十六进制与截断展示。实时记录不表示已写入 ClickHouse；忽略日志不会入库，详情显示临时缓存标识，不把 `eventId=0` 当作正式事件 ID。

暂停与向下滚动会停止此浏览器订阅并冻结当前画面，服务继续缓存；恢复通过缓存代次与游标补齐。断线自动有限重连，空闲连接仍有独立心跳；缓存重启、淘汰导致无法补齐时重新读取并显示缺口。清屏只影响当前浏览器，不清空服务缓存或数据库。该页面依赖显式迁移后的控制库，尚未迁移时展示对应提示，页面源码与隔离检查不代表生产部署或真实设备验收。

当前关键词仍仅支持区分大小写的 ASCII 全词 AND；中文、非 ASCII 与纯符号不支持。单次查询最多 30 天，可选择保留期内的历史时间；没有日志命中精确总数、跨年一次查询、告警、导出、回放或自动保留清理。解析器管理、细分角色、审计查询及容量治理页面尚未实现。后端限制见[运行与验证说明](../docs/spec/首批后端运行与验证.md)。账号分页有独立真实总数，不代表日志检索已实现计数。

MCP 页面位于 `/system/mcp`，仅管理员可访问。Key 创建后不能编辑，空有效期为永久，只有吊销后才能删除；删除不移除调用历史。复制指令从当前浏览器的协议、主机和端口生成 `/mcp` 地址，剪贴板不可用时显示可手动复制文本。调用详情按需加载并原样展示请求与响应，内容以纯文本转义呈现，不执行其中 HTML；仅该详情接口允许最多 32 MiB 的 JSON 传输响应，以容纳正文转义后的体积。MCP 调用记录的留存设置独立于设备日志，完整范围与迁移要求见 [MCP 设计](../docs/spec/MCP服务需求与设计.md)。前端源码与检查不代表服务器已部署。

「运行总览」的日志速率图用蓝色虚线显示接收速率，用绿色实线显示确认写入速率，用橙色虚线显示按来源规则忽略的速率，单位为条/秒。右上角默认选择「全部」，也可选择已登记的来源设备。切换来源后从该来源的首个样本重新开始绘图，其他看板指标仍显示全局值。新样本从右侧加入，超过 60 秒的样本从左侧移出。采样从页面打开后开始，刷新页面会重新累计样本。实时连接中断、暂停更新或服务重启后的采样缺口在图中留空。

在「日志来源」编辑设备可多选要忽略的严重级别。应用按最新来源快照过滤新报文，命中规则的报文只计入忽略量，跳过磁盘暂存和 ClickHouse 写入。已有版本 2 控制库需先执行显式迁移才能保存非空规则。

「接收配置」使用管理员接口保存四种协议设置。页面分别显示当前监听状态和已保存配置。保存后，关闭再开启「日志接收总开关」即可应用配置。接收已关闭时，保存后直接开启。总开关关闭时，日志监听端口和现有接收连接会关闭。默认提供 UDP/TCP 514、TLS 6514、RELP 2514 作为可修改的配置值，各协议初始监听地址为 `0.0.0.0`，总开关和各协议初始均关闭。TCP/TLS 可选择自动识别、字节计数或换行分帧，流式协议可调整单帧和空闲超时。TLS 的证书下拉框列出可用的系统证书和服务器预配证书，保存时提交证书标识。

监听状态下方按客户端 IP 显示连接错误。页面可见且正在接收时定期更新列表，同一客户端的新报文成功接收后，已恢复的错误行会消失。

保存前显示各协议的启停、地址和端口并要求确认，启用项为绿色，停用项为红色。切换总开关时也显示操作确认。页面提示版本冲突、证书缺失、端口冲突及读取失败。旧控制库需要通过显式维护命令迁移监听配置表。

## 语言、主题与使用文档

未登记设备仅保存在内存，重启后清空，不代表正式日志已入库。默认最多 1000 个 IP、64 MiB（包含元数据预算），达到容量或每 IP 的 100 条上限时淘汰最旧样本。页面显示允许网段、实际缓存占用、累计暂存、淘汰和拒绝计数；设备列表的日志摘要不含完整原始字节，打开样本后才读取原文。已登记但停用的来源不会进入该列表。

「添加为来源」直接使用 IP 作为名称、`Asia/Shanghai`、365 天和启用状态，成功后在来源页继续修改。登记后默认在 10 秒来源快照刷新周期内转入正常接收；此前样本不自动补入正式日志库。详细接收配置见[未登记设备暂存说明](../docs/spec/未登记设备暂存.md)。

- 点击右上角的地球图标，可切换简体中文、繁體中文、日本語、한국어、Русский或 English。登录、总览、日志检索与详情、来源管理和保留设置随界面语言切换。
- 点击右上角的账号名称可打开主题设置、修改密码或退出登录。主题提供自动、浅色和深色。首次访问默认使用自动模式，随操作系统外观切换。之前手动选择的主题保留在当前浏览器中。
- 修改密码时填写当前密码和 8～1024 字符的新密码，并再次确认新密码。新密码须包含非空白字符，且须与当前密码不同。修改成功后，系统结束该账号的所有会话，请使用新密码重新登录。
- 点击右上角的书本图标打开使用文档，可展开首次配置、账号、用户管理、总览、检索与原文、来源、保留各章节。文档正文随界面语言切换，简体中文配图不含真实账号或日志，点击图片可放大。
- 点击页面底部的通研标志或 `TongYanInfo Site`，可在新标签页打开[通研官网](https://www.tongyaninfo.com)。

首次打开未配置账号的系统会进入管理员配置页。正式提交只接受服务器本机 HTTPS 直连，远程安装可使用受控隧道，完成后按常规入口登录。不会因控制库故障重新开放管理员注册，也不预设默认账号。所有新增账号当前均为管理员，修改用户名、停用或重置密码会撤销目标账号的会话。界面不会提供账号删除或把只读角色标为可用。

## 安装与检查

在前端目录执行：

```sh
npm install --ignore-scripts
npm run setup
npm run lint
npm run test
npm run build
```

隔离验证可设置 `SYSLOG_BUILD_OUTPUT_PATH` 为一个新的独立目录，再运行 `npm run build`；不指定时仍输出到 `dist/`。构建工具会清理目标输出目录，因此不得将隔离输出指向既有制品或后端 `wwwroot`。

首次安装显式忽略依赖生命周期脚本，避免引入 Git hooks 等额外动作，再用 `setup` 生成 Umi 文件。已有锁文件的可复现安装可使用 `npm ci --ignore-scripts`，之后同样运行 `npm run setup`。本项目没有 `prepare` 或模板裁剪脚本，不安装全局依赖。

`npm run dev` 仅绑定 `127.0.0.1:8018`，用于前端开发。它不提供生产会话环境；真实登录联调需要获准的同源 HTTPS 后端及证书配置，不能为开发放宽 Secure Cookie、HTTPS 或来源校验。

## 合成预览与后端制品

日常测试首次管理员、用户管理与实时看板应使用[真实后端运行说明](../docs/spec/首批后端运行与验证.md)。SignalR 使用同源 HTTPS 与当前 HttpOnly 会话 Cookie，连接失败不会退回合成数据或定时 HTTP 轮询。下列历史合成工具仅保留给静态交互验证，不实现 SignalR，不能验证实时看板和真实持久化。

在已获准的本地预览范围内，先构建再执行：

```sh
npm run build
npm run preview:synthetic
```

合成预览默认监听 `127.0.0.1:8019`，从 `dist/` 提供管理台页面与内存合成 API。页面标注合成数据，适合查看界面和验证交互。真实接收与查询性能需要在目标环境验收。

明确获准从局域网访问时，可在前端目录使用以下命令。

```sh
SYSLOG_PREVIEW_HOST=0.0.0.0 npm run preview:synthetic
```

浏览器使用本机实际 IPv4 地址和 `8019` 端口访问。此模式也保留 `http://127.0.0.1:8019` 入口。预览服务校验访问主机和写请求的同源信息，场景切换接口仅接受回环访问。

浏览器打开 `http://127.0.0.1:8019`，使用合成账号 `preview`、合成密码 `preview-only` 登录。这是[预览脚本](scripts/preview-synthetic.mjs)内公开的测试数据，不是系统默认管理员或真实凭据；不能用于生产登录。脚本使用独立的 `syslog_preview` Cookie，不改变后端生产会话设置。必须先生成 `dist/index.html` 才会监听；页面标识仅在响应中注入，不改写构建文件。

正常场景含 3 个文档保留网段来源与 300 条最近约 50 分钟的合成日志。最新三条依次提供 HTML/脚本文本、64 KiB 合法 UTF-8 原文、非法 UTF-8 字节，供验证文本转义、截断及编码提示。来源新增、编辑及保留设置仅写入进程内存，重启或切回 `normal` 会恢复初始样本，不保留测试修改。

合成预览的「清空日志」清除当前进程中的样本日志。切回 `normal` 可重新生成样本。

「未登记设备」的正常预览另含两个文档保留网段 IP，各展示 100 条近期样本及容量淘汰统计，提供脚本文本、超长原文和非法编码样本。一键登记后从待登记列表隐藏；`empty/error/save-error/expired` 场景同时覆盖新页面。该预览不运行真实接收缓存，缓存配额行为由后端合成测试验证。

「接收配置」的预览包含四种默认关闭的监听配置。保存更新待生效快照，重新开启总开关后，界面显示新的模拟监听端口。合成预览在内存中模拟切换。预览没有可选 TLS 证书，启用 TLS 时会提示缺少证书。`error/save-error/expired` 同样适用于该页面。可通过 `SYSLOG_PREVIEW_DIST` 指定隔离构建目录。

用户管理初始展示 `preview` 和 `ops-example` 两个合成管理员。首次配置和新增账号可填写合成用户名，浏览器仅发送固定样本密码，所有预览账号都使用公开样本密码 `preview-only` 登录。预览中的密码重置模拟会话撤销，不保存或改变实际输入的密码。切回 `normal` 会恢复初始账号并清除预览会话。

预览中的修改密码会演示校验、会话失效和返回登录页的过程。重新登录时继续使用合成账号的原测试密码。

可通过下面的预览专用接口切换测试场景；将 `empty` 替换为表中的场景值。请求必须携带 `X-Syslog-Request: 1`，并访问上述 `127.0.0.1` 地址：

```sh
curl --request POST 'http://127.0.0.1:8019/__preview/scenario' \
  --header 'Content-Type: application/json' \
  --header 'X-Syslog-Request: 1' \
  --data '{"scenario":"empty"}'
```

| 场景 | 合成行为 |
| --- | --- |
| `normal` | 恢复初始来源、日志与正常状态；重新生成最近时间的日志 |
| `empty` | 来源与日志为空，状态指标为零且接收关闭 |
| `error` | 状态、来源读取及日志请求返回 503；会话查询继续可用 |
| `save-error` | 仅来源新增与编辑返回 503，便于检查保存失败后的表单保留 |
| `expired` | 当前会话失效，管理请求及登录返回 401；切回 `normal` 后重新登录 |
| `setup` | 清空合成账号与会话，刷新任意页面进入首次管理员配置；配置后用填写的合成用户名和固定预览密码登录 |
| `setup-blocked` | 展示首次配置的本机提交限制，不能提交表单 |
| `setup-error` | 初始化状态接口返回 503，页面只能重试，不能误判为无账号 |

切换场景后刷新相应页面或手动重试即可观察结果。场景接口只属于本地合成预览，不随前端构建加入生产 API，也不替代真实数据库、认证安全、设备接入或性能验收。

需要生成后端静态制品时执行：

```sh
npm run build:backend
```

[复制脚本](scripts/copy-to-backend.mjs)将当前产物写入 `backend/src/Syslog.Api/wwwroot`，排除 source map，不删除既有文件。历史哈希资源可能累积，回收须作为单独获准的维护操作处理，不能把复制等同于完整发布或旧文件清理。生产 API 始终使用同源 `/api/admin/v1` 与 HTTPS、安全 Cookie，不依赖开发代理、合成 API 或外部字体。

## 约定

- 路由在 `config/routes.ts`；
- 页面在 `src/pages/`；
- 请求封装在 `src/services/`；
- 界面文案位于 `src/locales/`，图文帮助位于 `src/components/HelpDocs/`，配图位于 `public/assets/help/`；
- 主题设置沿用模板的 defaultSettings 和 Ant Design token；
